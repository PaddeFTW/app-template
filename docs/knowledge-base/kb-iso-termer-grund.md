# Grundläggande termer för ledningssystem

Säg **krav** och **avsnitt**. Inte klausul.  
Dessa ord används i alla Quality Works-appar som grund.

## Gemensamma ord

| Ord | Enkel förklaring |
|-----|------------------|
| Ledningssystem | Så ni styr verksamheten så att ni uppnår det ni lovat (kvalitet, miljö, arbetsmiljö eller informationssäkerhet). |
| Kontext | Vad som påverkar er: kunder, lagar, personal, marknad, klimat, teknik. |
| Intressent | Den som ställer krav eller påverkas: kunder, personal, myndigheter, ägare, grannar. |
| Omfattning | Vad systemet gäller och inte gäller. Till exempel hela bolaget eller bara en avdelning. |
| Process | En kedja av aktiviteter som ger ett resultat. Till exempel från offert till leverans. |
| Risk | Något som kan gå fel och påverka resultatet. |
| Möjlighet | Något ni kan vinna på om ni agerar. |
| Bindande krav | Lagar, föreskrifter, avtal och andra krav ni måste följa. |
| Policy | Kort beskrivning av vad ledningen vill med systemet. Personalen ska kunna säga det med egna ord. |
| Mål | Vad ni vill uppnå. Ska kunna följas upp. |
| Dokumenterad information | Det ni behöver ha skriftligt eller sparat för att styra och visa att ni gjort rätt. |
| Avvikelse | Något som inte blev som planerat. Tas om hand med orsak och åtgärd. |
| Korrigerande åtgärd | Åtgärd som tar bort orsaken så att det inte händer igen. |
| Förbättring | Ständiga små eller stora steg för att bli bättre. |
| Intern revision | Egen kontroll att systemet fungerar. Inte samma sak som extern certifieringsrevision. |
| Ledningens genomgång | Möte där ledningen tittar på hur systemet fungerar och beslutar om förbättringar. |
| Bevis | Det en revisor eller kund kan se: protokoll, foto, logg, avtal, kvittens. |

## Vad appen ska säga

- Använd dessa ord konsekvent i alla appar.
- Anpassa exempel efter bransch, men behåll orden.
- Säg “avsnitt Kontext” i stället för “4.1”.

## Vanligt fel

Att använda olika ord för samma sak i olika appar. Använd denna lista som gemensam grund.
