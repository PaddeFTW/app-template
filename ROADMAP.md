# Roadmap

## Current Milestone

Establish the official Quality WorX frontend starter foundation.

## Phase 1

- bootstrap Next.js, TypeScript, and Tailwind
- establish semantic design tokens
- provide neutral UI primitives
- provide reusable layout shells
- document architecture and design rules

## Phase 2

- add form-field composition patterns
- add data-display patterns beyond the initial table primitive
- expand theme customization guidance
- add accessibility review checklist
- add richer docs in `docs/`

## Phase 3

- introduce optional testing patterns for shared UI
- add optional Storybook or equivalent design review tooling
- add template-level CI recommendations
- document migration and versioning strategy for future starter updates

## Phase 4

- evaluate extraction into a shared internal package structure if multiple apps need synchronized components
- formalize contribution workflow for platform maintainers
- publish starter release process and governance

## Out of Scope

- product workflows
- backend integrations
- product data models
- role or permission logic
- Quality WorX module implementations
